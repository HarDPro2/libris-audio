# Diccionario español para hunspell

Archivos `es_ES.aff` y `es_ES.dic`, incluidos **sin modificar**.

**Origen:** proyecto LibreOffice / RLA-ES (paquete Debian `hunspell-es` 1:24.2.1).

**Licencia:** triple — **MPL-2.0**, LGPL-3 y GPL-3+, a elección del usuario.

Se incluyen bajo **MPL-2.0**, que es copyleft por archivo: permite distribuir
estos ficheros dentro de un producto comercial cerrado siempre que (a) no se
modifiquen, (b) se conserve este aviso, y (c) su fuente siga disponible en el
proyecto de origen.

No se enlaza con ningún código de hunspell. Se leen con **spylls** (MIT), que
es un lector de formato hunspell escrito en Python puro.

Si alguna vez hay que modificar el diccionario, las palabras propias van en un
archivo aparte, nunca dentro de estos dos.
